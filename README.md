# PetShop Cão Feliz - Fase 2

Projeto acadêmico da disciplina com evolução da Fase 1 para a Fase 2.

## Funcionalidades implementadas

- Estrutura visual com Bootstrap e CSS personalizado
- Carrossel de imagens na página inicial
- Seção de produtos e serviços com layout responsivo
- Formulário de cadastro do cliente e do pet
- Agendamento de serviço com escolha de:
  - banho ou tosa
  - tele-busca ou entrega do pet no local
  - data e horário
- Funções em JavaScript para:
  - saudação dinâmica
  - data mínima para agendamento
  - máscara de CPF
  - máscara de telefone
  - validação do formulário
  - resumo do agendamento na tela
- Recurso de acessibilidade:
  - atributo alt nas imagens
  - labels associadas aos campos
  - link "Pular para o conteúdo principal"
