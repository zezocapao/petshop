# Arquivo de Ajuda - PetShop Cão Feliz

## Como usar a página

1. Acesse o menu superior para navegar entre as seções.
2. Veja os destaques no carrossel inicial.
3. Consulte os produtos e serviços disponíveis.
4. Vá até a seção **Cadastro e Agendamento**.
5. Preencha os dados do cliente e do pet.
6. Escolha o serviço desejado.
7. Selecione o método de atendimento.
8. Defina a data e o horário do agendamento.
9. Clique em **Confirmar agendamento**.
10. O sistema exibirá um resumo do agendamento na própria tela.

## Requisitos atendidos nesta fase

- Uso de CSS e Bootstrap
- Uso de JavaScript
- Formulário com diferentes tipos de campos
- Agendamento com data e hora
- Recurso de acessibilidade para deficientes visuais
- Organização do código em arquivos separados
